For this project, I wanted to create a black hole with colorful rings around it. I started by making the rings and experimented with different colors, sizes, angles etc. When running my code I stumbled upon an interesting composition where it drew new rings each frame and decided to use this as part of my work. I used randomization to change the black holes outer edge as well as the ring color, size, and position. I also used randomization to draw a cloudy nebula and stars in the background. Since it draws every frame the stars make it look like you're moving through outer space, and the rings add to the chaos. Ultimately, I wanted to create a composition that looked stationary yet moving at the same time.
